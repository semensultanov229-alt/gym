# LEVEL 1. Вывод в STDOUT

В этом задании мы разберем какие есть типы данных. Мы создадим переменные и узнаем их тип.

Создай переменные и укажи следующие значения:
* Твое имя
* Сколько тебе полных лет
* Значение числа Пи
* Любишь ли ты программирование (True или False)

Теперь используй метод для того, чтобы узнать типы этих переменных, и выведи их в терминал.

# LEVEL 2. Ввод из STDIN

Теперь напишем программу, которая узнает как зовут пользователя, который ее запустил, и какой у него любимый язык программирования.

Программа должна выдавать приветственный вывод в терминал.

# LEVEL 3. Калькулятор

Давай сделаем простой кальькулятор.

Пользователь ввод сначала первое число, потом второе.

А программа выведет следующие значения с этими числами:
* Сумму
* Раность
* Произведение
* Деление
* Среднее арифметическое

Не забудь про граничные значения, при которых программа будет вести себя некорректно!

# LEVEL 4. Условные операторы

Давай расширим возможности программы из LEVEL 2.

Программа должна спрашивать любимую технологию и в зависимости от ввода выводить следующие из вариантов:

* Если технология связана с фронтендом, то вывести: "Фронтенд отличный выбор! Создаёте красивый и отзывчивый интерфейс."
* Если с бекендом: "Бекенд, сила и надёжность! Держите серверную часть под контролем."
* Если с Data science: "Data Science, мир данных! Данных много не бывает."
* DevOps: "DevOps! Строите надёжную инфраструктуру?"
* Если ничего из этого не подходит, то: "Ого, какая нишевая технология. Даже гугл не знает о ней!"

Подумай как хранить список этих технологий. И не забывай о том, что пользователь может ввести совершенно нЕпРеДсКаЗуЕмЫй текст

# LEVEL 5. Колесо фортуны рынка труда

Мы продолжаем работать с программой LEVEL 4.

Теперь у нас есть вакансия Junior Backend.

Подходят только резюме, в которых присутствует строго:
* Опыт работы от 1 года до 3 лет
* Наличие пет-проектов
* **Оконченное** высшее образование

Программа должна спрашивать из stdin данные характеристики.

Если всё это есть, то кандидат подходит.

Но если отсутствует что либо из этого, то кандидат заносится в кадроый резерв.

Иначе придется ему отказать :(

# LEVEL 6. Время поиграть

Загадай целое число (например, 7).

В цикле спрашивай у пользователя число

* Если число меньше загаданного, то говори "Больше!"
* Если больше, то "Меньше!"
* Если угадал, то выводи "Победа!" и выходи из цикла

Игра должна продолжаться, пока не угадают число.

# LEVEL 7. Таблица умножения

Пользователь выбирает число, а программа выводит таблицу умножения от 1 до 10.

Пример, если пользователь вводит 7:
7 x 1 = 7
7 x 2 = 14
...
7 x 10 = 70

# LEVEL 8. Список знакомых технологий.

Создай программу, которая собирает информацию о знакомых технологиях пользователя:

* Начни с пустого списка
* В цикле спрашивай: "Какие технологии Вы знаете? (или 'стоп' для выхода)"
* Добавляй каждый ответ в список
* Когда пользователь введёт "стоп" выведи:
    * Всё, что в списке
    * Количество используемых технологий

# LEVEL 9. Работа со строками

Напиши программу, которая:

* Спрашивает у пользователя любое предложение
* Выводит:
    * Это же предложение ЗАГЛАВНЫМИ БУКВАМИ, мальенькими буквами, Каждая Первая Буква Заглавная
    * Количество слов в предложении
    * Каждое слово с новой строки
    * Первое и последнее слово

# LEVEL 10. Функции

Создай функцию приветствие_героя(имя, уровень), которая:
* Принимает имя и уровень программирвоания
* Возвращает текст: "Герой [имя], ты достиг [уровень] уровня!"

После создания функции:
* Спроси у пользователя его имя и уровень
* Вызови функцию с этими данными
* Выведи результат на экран
